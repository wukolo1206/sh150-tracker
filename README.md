# 🏃 SH150「跑跳遊臺灣」班級每日運動圈數登記與 A4 列印系統

新北市三重區碧華國小四年八班（408）SH150 健康促進活動每日運動圈數登記系統。

## 🌟 核心功能

- 📱 **學生平板 / 大螢幕觸控友善**：大按鈕一指點選，支援 +1圈、+2圈、+5圈 與 +100下、+200下 快速登記。
- 📅 **自動日期推算**：以開學週一（2026/08/31）為基準，自動推算開學週次與每週星期一至五日期（包含上一週/下一週切換）。
- 🧮 **智能折算公式**：
  - 學生跳繩：每 **200 下** 自動折算操場跑步 **1 圈**（依學務處正式審查標準）。
  - 導師跑步：圈數自動 $\times 2$ 加倍計入班級成績。
  - 當日採計總圈數與全週總圈數自動加總。
- 🖨️ **A4 完美一鍵直印**：內建 @media print 排版，列印時自動轉換為完全吻合體育組紙本格式的單頁 A4 直式表格。
- 💾 **離線資料庫與備份**：使用瀏覽器 localStorage 保存紀錄，並支援 JSON 匯出與匯入備份。
