# 頁尾版本標示設計

## 目的

讓使用者不用查看網址或 GitHub 提交紀錄，就能在系統頁面辨識目前使用的版本。

## 範圍

- 在 `universal.html` 頁面最下方顯示「第 17 版」。
- 版本標示只出現在螢幕操作介面，不納入 A4 列印內容。
- 不修改週次自動判定、學生資料、LocalStorage 資料格式或既有功能。
- 本次不新增版本切換功能，也不變更版本編號規則。

## 實作設計

- 在既有非列印介面容器內新增版本標示元素，沿用現有樣式系統。
- 文字固定為「第 17 版」，不顯示 commit hash。
- 使用具語意的 `id`，方便回歸測試確認版本標示存在。
- 版本標示採低干擾樣式，置於頁面底部並與主要操作區分開。

## 驗證方式

- 靜態檢查確認頁面包含「第 17 版」及其識別元素。
- 內嵌 JavaScript 語法檢查通過。
- 確認列印樣式不會顯示版本標示。
- 確認既有週次自動判定測試與日期變數回歸測試仍通過。

## 部署

完成驗證後，僅提交 `universal.html` 的功能變更，推送至 GitHub `main`，再檢查 GitHub Pages 公開頁面。
